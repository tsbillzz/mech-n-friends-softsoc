# **App Name**: Sydney PC Finder

## Core Features:

- Campus Map Display: Display a map of the University of Sydney campus with library buildings highlighted.
- Real-Time PC Availability: Show real-time availability of PCs in each library building.
- Color-Coded PC Status: Display available PCs as green squares and occupied PCs as red squares.
- Building Zoom: Allow users to zoom into specific buildings to view PC availability by floor.
- AI Availability Forecaster: Use past PC usage patterns to predict the future PC usage using a predictive tool, displayed via a simple availability indicator.

## Style Guidelines:

- Primary color: Deep teal (#008080) to reflect an academic and calming environment.
- Background color: Light teal (#E0F8F7), creating a soft and clean backdrop.
- Accent color: Muted coral (#F08080) for highlighting key interactive elements.
- Body and headline font: 'PT Sans', a humanist sans-serif for a balance of modernity and approachability.
- Use simple, clear icons to represent buildings, floors, and PC status (e.g., green check for available, red cross for occupied).
- Ensure a clean and intuitive layout, prioritizing the campus map and PC availability indicators.
- Implement subtle transitions and animations for zooming into buildings and updating PC status.
